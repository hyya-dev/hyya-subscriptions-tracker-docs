# Security

## Report a security problem privately

If you find a security problem in hYYa Subscription Tracker, such as a way to see another person's subscriptions or receipts, to add or change data on someone else's account, or to get a paid plan without paying, please tell us **privately** by **[email to our security team](mailto:security@hyya.com?subject=hYYa%20Subscription%20Tracker%20security%20report)**, or through [hyya.com/contact.html](https://hyya.com/contact.html). In the app, **Settings › About › Report a Security Issue** opens the same email.

**Please don't open a public issue for it.** Issues in this repository are public as soon as they are filed, and a problem described here before it is fixed puts every user at risk.

Tell us, if you can:

- the device and system (for example, iPhone with iOS 26, or Android 15),
- the app's version, shown on its App Store or Google Play page,
- what you did and what happened, and
- an example, made up rather than real. Please don't send anyone's private receipts.

## What happens next

We read every report. We reproduce the problem, fix it on each platform it affects, and tell you when the fix is out.

## Which versions get fixes

Only the current version on each store. Updating from the App Store or Google Play is the fix.
